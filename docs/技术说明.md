# 技术说明：这版汉化是怎么做的，以及哪些地方做不动

## 1. 文本的载体

- **场景对话**：42 个 `*.SNR` 文本池。每个池尾部有一张「每记录偏移表」，
  引擎靠它定位每句台词；文本长度一变，整池位移，表必须按新位置重建。
  v3 的做法是逐档校验「表项 + 0x40 == 记录起点」，42/42 全部命中。
  不做这一步的典型症状：整片空白对话框、句尾残留假名与数字、句首被吃掉。
- **系统文本**：`1RENTA.BIN` 的 `0x0C6000–0x0DC800` 一带是界面文本槽区，
  按槽写入；其中少数槽原版就是表格 / 指针 / 假名字盘，没有文字可写。
- **其它散落字符串**：道具名与说明、委托单模板（委托主／报酬／地点）、受托物提示、
  技名与技说明、商店与旅馆对话、银行与 SECA 缴费提示、卡片评语、变身开关、邮件。
  这些分布在不同文件里，逐一定位、逐条替换。

## 2. 排版：19 格 × 3 行

原版单行 20~21 格，实测对话框内可用宽约 750px。
中文全角字占两格，14 格会把较长句子挤成第 4 行（超出框）；
最终定在 **19 格、最多 3 行**，全盘不再出现 4 行记录。
需要强制换行的地方用「／」标记，人名用【】占位，道具名用＠标记，规则沿用译文表。

## 3. 字库

字库文件按原版规格重建，流程是：

```
48px 渲染单字 → 取墨迹包围盒 → 缩放到 21 格 → 24×24 居中 → 三级量化
```

关键是"墨量与原版一致"：量化级别照抄原字库，避免中文看起来比日文更淡或更糊。
与日文同形的字沿用原码位，简体专有的字分配空槽；早期版本因槽位不够而"借近义字顶替"的那些字，
后来按上述流程补绘进空槽后改回本字，已有码位一格未动，所以对白与界面文本不受影响。

## 4. 为什么「参数」页还是日文

菜单「参数」页的页签（アイテム／カギ／バトル／プレゼント）和五档台词速度的文字，
**不是字库字，不是贴图，是盘内的多边形几何文字**——每个字是一组顶点坐标，
直接由渲染管线当图形画出来。要换字，得按目标汉字的笔画重排顶点数据、重算宽度与字距，
等于给这套引擎写一个"汉字转几何"的生成器。本版没有处理这一块。

同类还有：起名页的「ひらがな／カタカナ」页签是烤进 PVR 贴图的图形字；
开场 2D 像素风过场与"谜之便条"的谜面走独立脚本，不在文本池内。
这些都在发布说明里写清楚了，没有藏着。

## 5. 难度评估

这游戏的汉化难度大概是《莎木》的四倍。不是因为世嘉加密——
是世嘉把 Dreamcast 的机能榨到了极限：数据结构与运行时行为绑死，
改一处连带修一片，能下手的入口极少。

按发布时间，这游戏的翻译目前只有三种：

| 版本 | 时间 |
|---|---|
| 日文原版（SEGA，HDR-0074） | 2000 |
| 英文补丁（Rent-A-Modders / VincentNL 等） | 2023 |
| 简体中文（本作，@FibrizoReturns） | 2026 |

所以能做完一版已经很不容易，短期内没有"下一版计划"。
